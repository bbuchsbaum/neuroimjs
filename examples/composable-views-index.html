🧠 Composable Views

Build custom neuroimaging viewer layouts with ease

What are Composable Views?

neuroimjs now provides SingleSliceViewer and ViewSynchronizer components that let you create individual orientation views (axial, sagittal, coronal) and wire them together in any custom layout you need.

Perfect for integrating into existing applications, creating custom panel arrangements, or building views that span multiple windows or GUI frameworks.

Run any demo with npm: npm run demo:single-view # Single axial view npm run demo:two-view # Two synchronized views npm run demo:multi-panel # Multi-panel custom layout

🚀 Quick Start

Creating a single view is as simple as:

import { VolStack, SingleSliceViewer } from 'neuroimjs'; const volStack = await VolStack.fromNifti('brain.nii.gz'); const viewer = await SingleSliceViewer.createAxial( container, volStack, { showCrosshair: true } );

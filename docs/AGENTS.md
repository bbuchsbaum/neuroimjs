# docs

## Purpose
Source of the documentation site (VitePress, deployed to GitHub Pages under `/neuroimjs/`) plus a few contributor notes that are excluded from the site.

| File | Description |

## For AI Agents

### Working In This Directory
- Verify every claim against `src/` (and run snippets) before documenting it; the guide is meant to be true, not aspirational.
- New pages must be added to the sidebar in `.vitepress/config.ts`; notes that should stay off the site go in `srcExclude`.
- `npm run docs:build` builds the API reference and the site.
- Do not hard-code the package version in prose; say "the 0.5 series" or link the changelog.
